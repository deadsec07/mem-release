# Memory Releaser

Memory Releaser is a tab-discard utility by A A Hasnat and HNE Technologies. It helps Chrome free memory by discarding background tabs while keeping the active tab available, with controls for pinned, audible, and whitelisted tabs.

Links:
- GitHub: https://github.com/deadsec07/mem-release
- Main site: https://hnetechnologies.com/
- Creator profile: https://deadsec07.github.io/

## Features
- Discards background tabs after a configurable grace period
- Skips audible, pinned, or whitelisted tabs
- Manual release button in the popup
- No host permissions and no content scripts
